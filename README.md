# Multimodal PINN for Elastoplastic Parameter Identification

Official code and data repository for the article:

**"Multimodal data fusion based on physics-informed neural networks for inverse identification of bilinear elastoplastic material parameters"**

This repository contains the complete implementation of the multimodal
physics-informed neural network (MM-PINN) framework for inverse identification
of bilinear elastoplastic constitutive parameters (elastic modulus E, Poisson's
ratio nu, yield strength sigma_y, and hardening modulus H) from full-field
displacement data and global force-displacement responses.

## Repository structure

```
|-- main_phase1.py                     # MM-PINN training and evaluation code
|-- sensitivity_threshold_analysis.py  # Threshold sensitivity and noise robustness analysis
|-- data/
|   |-- all_training_data.csv          # Training dataset (200 parameter sets, LHS sampling)
|   |-- force_displacement_data.csv    # Force-displacement curves
|-- trained_model/
|   |-- multi_modal_pinn_model.pth     # Trained model weights
```

## Requirements

- Python >= 3.10
- PyTorch >= 2.0
- NumPy, pandas, scikit-learn, matplotlib, tqdm

```bash
pip install torch numpy pandas scikit-learn matplotlib tqdm
```

## Usage

Training and evaluation:

```bash
python main_phase1.py
```

Threshold sensitivity and noise robustness analysis:

```bash
python sensitivity_threshold_analysis.py
```

## Data description

The training dataset consists of 200 sets of bilinear elastoplastic parameter
combinations generated by Latin hypercube sampling over the ranges:
elastic modulus 180-220 GPa, Poisson's ratio 0.27-0.33, yield strength
250-350 MPa, and hardening modulus 1-10 GPa. For each parameter combination,
the full-field displacement data and the force-displacement curve were obtained
from finite element simulations (ABAQUS) of a notched tensile specimen.
